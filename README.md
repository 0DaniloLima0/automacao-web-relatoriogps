# 🤖 Automação Web - Relatório GPS

Automação de alta performance desenvolvida em **Python** utilizando **Playwright** para extração, download e tratamento de relatórios web. O script automatiza o fluxo de login, captura de arquivos e organização de planilhas Excel.

## 🚀 Diferenciais Técnicos
* **Playwright:** Navegação rápida e estável com espera automática de elementos.
* **Tratamento de Dados:** Uso de `openpyxl` para manipulação automática de abas e formatação de arquivos baixados.
* **Segurança:** Implementação preparada para variáveis de ambiente (evitando exposição de senhas).
* **Resiliência:** Tratamento de exceções com blocos `try/except/finally`.

## 🛠️ Tecnologias
* [Python 3.x](https://www.python.org/)
* [Playwright](https://playwright.dev/python/) (Navegação Automática)
* [Openpyxl](https://openpyxl.readthedocs.io/) (Manipulação de Excel)
